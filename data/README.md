# Data

This directory contains example input data and directories used for outputs generated by the Logging Trail Analyzer (LTA).

## Example data

The `example` directory contains anonymized data for two example sites:

- `site02/` — GNSS logging tracks (`Trails2`) and harvesting-site boundary (`Area2`)
- `site04/` — GNSS logging tracks (`Trails4`) and harvesting-site boundary (`Area4`)

The example spatial data use ETRS89 / UTM zone 35N (EPSG:25835).

Only example data are provided. The complete research dataset is not distributed in this repository.

## Generated outputs

The LTA scripts use the following directories:

- `LTA_outputs/` — derived logging trail centrelines and machine-pass analysis outputs
- `buffer/` — intermediate spatial outputs used in trail-network analysis
- `Output_vis_NEW/` — final visualization outputs
