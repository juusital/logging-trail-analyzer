# Example Site 04

This directory contains anonymized example spatial data for demonstrating the Logging Trail Analyzer (LTA) workflow.

The example includes:

- `Trails4` — forest-machine GNSS tracks
- `Area4` — harvesting site boundary

Coordinate reference system: ETRS89 / UTM zone 35N (EPSG:25835).

The complete research dataset is not distributed in this repository.
